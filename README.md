# التعريب العربي لـ Mindustry | Arabic Localization for Mindustry

مود تعريب عربي كامل لواجهة لعبة Mindustry (حوالي 3000 نص) مع خط عربي مدمج.
A full Arabic translation mod for Mindustry (~3000 strings) with a bundled Arabic font.

## التثبيت | Install
- من متصفح المودات داخل اللعبة: ابحث عن **arabic-localization** / In-game: Mods → Mod Browser → search "arabic".
- أو: Mods → Import Mod → Import from GitHub → أدخل `USERNAME/REPO`.
- بعد التثبيت أعد تشغيل اللعبة بالكامل | Restart the game fully after installing.
